# Proofline Problem Interview

1. Walk me through the last production release from code complete to approval.
2. How did you decide which regression tests to run?
3. Where were requirements, automated tests, manual checks and results recorded?
4. Show me the release report or evidence used for the decision.
5. What was blocked, skipped, flaky or untested, and how was that represented?
6. How many people and hours were involved?
7. Which current tools are paid, and what would break if you removed them?
8. Tell me about the last escaped defect related to missing or misleading evidence.
9. Rank release planning/evidence among your top five QA pains.
10. Would you install a metadata-only CLI in a Playwright repository this month?

Do not pitch until question 10 is answered. Record exact examples, not opinions alone.
